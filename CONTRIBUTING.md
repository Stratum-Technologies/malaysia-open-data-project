# Contributing

Thank you for helping map Malaysian data.

## What belongs here
A listing should point to a real resource useful for obtaining, querying, purchasing, requesting or otherwise accessing data relevant to Malaysia. Public, private, commercial, academic and controlled-access sources are all in scope.

## Before submitting
Search existing records by title, publisher and URL. Prefer the original publisher over a third-party mirror. One logical resource should have multiple endpoints rather than duplicate listings.

## Two contribution paths
Technical contributors should edit the relevant YAML and open a pull request. Everyone else can use the `New data resource` issue form.

## Evidence
Do not guess licence, access restrictions, update frequency or temporal coverage. Use `unknown` or omit optional metadata when it cannot be verified. Provide provenance where the discovery path is useful.

## Review
Maintainers may normalize titles/tags, merge duplicates, request evidence, or reject sources that are unlawful, unsafe, purely promotional, not meaningfully data-related, or impossible to describe without misleading users.
